Система автоматизированного анализа отчетов о техническом обследовании многоквартирных домов (МКД) с целью определения приоритетности расселения аварийного жилищного фонда. Проект разработан для ППК «Фонд развития территорий» и Министерства строительства РФ.

Целью раюоты является разработка автоматизированной системы для анализа отчетов о техническом обследовании зданий, позволяющую:
- Извлекать информацию о состоянии всех несущих конструкций
- Классифицировать состояние по 4 категориям ГОСТ 31937
- Выявлять угрозу обрушения и другие критические дефекты
- Определять приоритет расселения зданий
- Хранить историю отчетов и проводить сравнительный анализ

Что сделано:
- Собраны и размечаны фрагменты текстов из отчета. Датасет состоит из 1050 строчек с классификацией на 4 класса;
- Обучена ML-модель: состояит из ансамбля из 3 моделей (SBERT, TF-IDF+LinearSVC, XGBoot), точность 90%, состоит из гибрида ml-модели и регулярный выражений для точности;
- Извлечение и очистка текста;
- Разделение слипшегося текста;
- Поиск конструкций, извлечение и очистка частей зданий;
- Поиск угроз обрушений и разбивка на секций;
- Загрузка PDF и пакетная обработка + вывод об общем вердикте здания;
- Разбивка по категорям, осям, конструкции без привязке к части здания, рекомендации;
- Хранение истории и отчетов, проверка дубликатов.
- Сравнение 2-х отчетов;
- Доп. критерии: судебные решения (если они есть в отчете);
- Отображение всех отчетов и дательный просмотр каждого отчета при пакетной обработки;
- переход на бд;
- сделала архитектуру: загрузка pdf, извлечение конструкций, далее ml определяет статус, потом раг ищет похожие конструкции в базе из тех 60 отчетов, а потом llm генерирует описание на основе конструкций, статуса и контекста.
- ускорила анализ отчетов.
